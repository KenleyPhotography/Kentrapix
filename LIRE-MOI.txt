KENTRAPIX — SITE + BACKEND (SUPABASE)

Le site fonctionne avec un vrai serveur : Node.js + base PostgreSQL sur Supabase.
Les photos sont sur Cloudflare R2. Le site en ligne est heberge sur Render.

DEMARRER EN LOCAL (details complets dans server/README.md)
1. Installez Node.js.
2. Dans un terminal :
     cd server
     npm install
     copy .env.example .env      (puis remplissez .env : DATABASE_URL Supabase + JWT_SECRET + R2)
     npm run db:init
     npm run create-admin
     npm run dev
3. Ouvrez http://localhost:3000

COMPTES
- Admin (studio) : cree avec "npm run create-admin".
- Clients : crees par l'admin dans Clients, avec un mot de passe temporaire.
  Le client choisit son propre mot de passe a la premiere connexion.
- Tout le site demande une connexion. Le studio est invisible pour les clients :
  le serveur refuse admin.html a toute personne qui n'est pas admin.

FICHIERS
css/modern.css    : style (bleu Kentra)
js/               : interface (appelle l'API du serveur)
server/           : backend et base de donnees
render.yaml       : configuration de l'hebergement Render
_ancien-css/      : sauvegarde de l'ancien design

IMPORTANT
- Ne partagez jamais server/.env et n'ecrivez jamais de mot de passe dans un autre fichier.
- Sauvegardes : Supabase (Database > Backups) pour la base, Cloudflare R2 pour les photos.
