Déploiement Cloudflare Worker KentraPix
=======================================
Le Worker « kentrapix » sert les fichiers statiques de dist/ et relaie les appels API
vers le backend configuré dans worker.js. La configuration et le build sont dans le dépôt.

Depuis la racine du dépôt :
     npx wrangler@latest deploy
   (wrangler.toml exécute npm run build, puis déploie dist/ et la route du domaine.)

Dans DNS, l'enregistrement de kentrapix doit être « Proxied » (nuage orange).
Test : attendre que le backend Render dorme,
   puis ouvrir le site : la page Bienvenue s'affiche, puis le site se charge tout seul.

Le sondage utilise /api/health.

Le Worker laisse passer les réponses qui portent l'en-tête X-Maintenance : c'est le site
lui-même qui est fermé par le studio (page « en cours de maintenance »), pas Render qui dort.
