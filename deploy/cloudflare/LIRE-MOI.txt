Page « Bienvenue » pendant le réveil de Render
===============================================
1. Cloudflare > Workers & Pages > Create > Worker, nom : kentrapix-bienvenue.
2. Depuis la racine du dépôt :
     npx wrangler@latest deploy
   (Wrangler utilise wrangler.toml pour déployer worker.js et la route.)
   Alternative : Edit code dans le dashboard avec tout le contenu de worker.js.
3. Dans DNS, l'enregistrement de kentrapix doit être « Proxied » (nuage orange).
4. Test : suspendre le service Render (Settings > Suspend) ou attendre qu'il dorme,
   puis ouvrir le site : la page Bienvenue s'affiche, puis le site se charge tout seul.
   (Reprendre le service ensuite.)
Le sondage utilise /api/health (déjà défini dans render.yaml).

Important : chaque fois que worker.js change ici, il faut le recoller dans Cloudflare
(Edit code > tout remplacer > Deploy). Le dépôt ne met PAS le Worker à jour tout seul.

Le Worker laisse passer les réponses qui portent l'en-tête X-Maintenance : c'est le site
lui-même qui est fermé par le studio (page « en cours de maintenance »), pas Render qui dort.
